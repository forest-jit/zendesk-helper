Match Harvest to your theme

Harvest styling starts off. Choosing a theme does not enable it.

  1. Click Match Harvest to theme below.
  2. Allow access to platform.harvestapp.com when Chrome asks.
  3. Check for Harvest theme on, then reload the Harvest panel using its reload icon.
